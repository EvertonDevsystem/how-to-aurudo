Tags aurudas (Obrigatórias)

São a base de qualquer página — sem elas o navegador não interpreta o conteúdo corretamente.


<!DOCTYPE html>

  • Para que serve: Avisa o navegador que usamos HTML5
  • Como usar: Sempre na 1ª linha, sem fechar

<html lang="pt-BR">

  • Para que serve: Envolve todo o código; define o idioma da página
  • Como usar: Abre logo após o doctype e fecha por último

<head>

  • Para que serve: Título, codificação, estilos e configurações
  • Como usar: Antes do conteúdo visível

<body>

  • Para que serve: Todo o que aparece na tela
  • Como usar: Apenas uma vez por página
Exemplo completo:
<!DOCTYPE html>
<html lang="pt-BR">
  <head><meta charset="UTF-8"><title>Minha Página</title></head>
  <body><p>Olá, mundo!</p></body>
</html>

Texto e Títulos com aura do 67 e for-two

<h1> a <h6> → Títulos por importância (apenas 1 <h1> por página)

<p> → Parágrafo de texto

<strong> → Destaque forte (negrito semântico)

<em> → Ênfase (itálico semântico)

Exemplo:
<h1>Título Principal</h1>
<h2>Subtítulo</h2>
<p>Este é um <strong>texto importante</strong> e este é <em>com ênfase</em>.</p>

Como tacar links e mídias aurudas

<a href="url"> → Cria links

<img src="foto.jpg" alt="descrição"> → Adiciona imagens

<ul><li> → Lista sem ordem

<ol><li> → Lista numerada

Exemplo:
<a href="https://google.com">Acessar o Google</a><br><br> <img src="logo.png" alt="Logotipo da marca"><br><br> <ul><li>Pão</li><li>Leite</li></ul>

Layout semântico sem aura 😒

<header> → Cabeçalho

<nav> → Menu

<main> → Conteúdo principal

<section> → Seção temática

<footer> → Rodapé

<div> → Agrupamento genérico

Exemplo:
<header>Logo e Nome do Site</header><br> <nav>Início | Sobre | Contato</nav><br> <main><section>Conteúdo da página</section></main><br> <footer>© 2026 - Todos os direitos reservados</footer>

Formulários para CLT

<form> → Área de envio de dados

<input> → Campos de texto, botões etc.

<button> → Botão de ação

Exemplo:
<form><br>   <input type="text" placeholder="Digite seu nome"><br><br>   <input type="email" placeholder="Digite seu e-mail"><br><br>   <button type="submit">Enviar Formulário</button><br> </form>
